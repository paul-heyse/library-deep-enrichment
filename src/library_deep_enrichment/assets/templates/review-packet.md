# Evidence review workflow

1. Export a packet for the exact task, candidate family and applicability profile.
2. Read each cited selection. A type signature supports interface facts; it does
   not establish null behavior, cancellation, consistency or copy guarantees.
3. Propose claims, mechanisms, conditions and exceptions using only offered IDs.
   Add capability facets and explain which claims support each facet.
4. Compare candidates against explicit requirements. Record what reverses the
   choice and which competing candidates still need investigation.
5. Import the response as drafts. Keep unsupported conclusions as open questions.
6. Run declared behavior examples. Record an exact-digest review with a rationale
   describing the supporting selections and remaining limits.
7. Build the generation. Inspect its rendered claim citations and coverage gaps.

Interactive file review is the primary workflow. A configured subprocess can
speak the same packet/proposal protocol; it cannot grant its own acceptance.
