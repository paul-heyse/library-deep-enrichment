# Development skills

Skills that help work on this repository go here. Codex and other agents read the same
directory through the `.codex/skills` and `.agents/skills` symlinks, so nothing drifts.

None are shipped yet by design. Library reference material is not a skill here: library
documentation is resolved through the Context7 MCP tools and exact-release facts through the
workers (see `.claude/rules/library-lookup.md`).
